## About

CLOOMC Technologies LLC develops the Church Machine — a capability-secured
processor architecture with an educational IDE for the Tang Nano 20K FPGA.
This repository hosts the cloomc.com website: documentation, licensing information,
and curriculum package details.

## Licensing — Three-Tier Model

### 1. Free Platform (GPL-3.0)
The core platform — IDE, simulator, CLOOMC++ compiler, shared library, and
hardware designs — is **free and open source** for all educational and personal use.
See [cloomc-project](https://github.com/khhodges/cloomc-project) for the full source.
